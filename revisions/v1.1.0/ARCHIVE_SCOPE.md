# DualFeat-SEW-CLIF revision evidence v1.1.0

This additive release contains code and existing summary evidence for manuscript
1966366 (article DOI: 10.3389/fnins.2026.1966366): exact-gradient Soft-CLIF;
shared-readout GRU-Stat/TCN-Stat; equal-update sensitivity; BCI2a binary sensitivity;
and firing rate, sparsity, operation proxy and GPU latency profiling.

All 536 runtime source-manifest files match their recorded hashes. The canonical
tree SHA-256 is 0330efd60134a83c2250682a465940c9b3c0dd49f410d9d02ac50da511da1950.
Existing resolved configurations, seeds, participant/seed metrics, paired summaries
and computational-profile files are included unchanged. No training, inference
or statistical recomputation was performed for this release.

## Explicit scope limitations

Formal revision trial-level classification predictions/logits were not located
in audited local archives and are NOT included. Historical or smoke predictions
are not substituted. Six timing arrays contain latency measurements, not logits.
Checkpoint barriers establish recorded provenance, not possession of weights.
Raw EEG, restricted feature/label caches, model weights, private session logs and
production proofs/figure attachments are excluded. This is not a complete
prediction-level archive and does not independently reproduce all reported results.
